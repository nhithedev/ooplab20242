- What class should implement the Comparable interface?

- Media class (the superclass) should implement Comparable<Media> to define a default natural ordering for all media types (DVDs, CDs, Books).
- Example of implementation: in Media class: @Override
    public int compareTo(Media other) {
        // 1. Compare titles (case-insensitive)
        int titleCompare = this.getTitle().compareToIgnoreCase(other.getTitle());
        if (titleCompare != 0) {
            return titleCompare;
        }
        // 2. If titles are equal, sort by cost (higher first)
        return Float.compare(other.getCost(), this.getCost());
    }
and use it in Collections.sort(mediaList); // Uses Media's compareTo()
